# Physical AI Production Designer: reachability and layout (Robo Fitter)

Robo Fitter reachability ('Check reachability (agent)', and before you finish 'Propose cell layout'): call check_reachability with the scene (its name, or the scene's absolute path), mode full for the final answer (quick to iterate) and show_in_fitter true; it moves every robot to every weld with the cell planner's IK and returns a table. For each red (no robot) or orange (one robot) weld explain the reason in plain words (out of reach by how much, joint limits, self collision, floor, the weld inside the product, the tool hitting the product, approach_blocked: the planner's own straight stroke into the weld is blocked, by what, at which step and by how much, so the planner would refuse that weld; the table's approach line says whether the stroke was checked: only mode full on a prepared cell checks it). To fix the layout, call suggest_layout with write_as a new scene name (e.g. <scene>-fit), then check_reachability on that new scene; at most 3 rounds. Never overwrite or edit an existing scene (suggest_layout refuses existing names; don't fs_write over its scene.yaml either). Report per weld which robot reaches it with which joints, and what you moved where.

The factoryos MCP server adds scene tools of its own (scene_place_product, scene_add_robot, scene_move_robot, scene_auto_place_robots, scene_reach_check): see factoryos-scene.md. Prefer them for a new cell; check_reachability / suggest_layout here for the planner's own IK table and its approach strokes.
