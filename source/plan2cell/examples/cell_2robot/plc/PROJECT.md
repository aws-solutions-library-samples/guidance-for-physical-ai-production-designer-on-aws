## Build routes

1. **MCP**: give an agent `MCP_PROMPT.md` (Windows CODESYS + MCP server).
2. **Manual**: follow the tables above; paste each declaration file into the declaration part and each `_Body.st` into the implementation part.

## Download and run (docker simulation)

Start the robot runtimes first (`docker compose -f docker-compose.yml -f <out>/docker/docker-compose.robots.yml up -d`), download each robot simulator project to its runtime, then the head PLC project to `codesys-master`. Set `PLC_PRG.bStart` (or keep `bAutoRun`).

## Known limitations

- Zones are logical ordering mutexes derived from the behaviour tree, on a standard (non-safety) PLC. They are not a substitute for safety-rated workspace monitoring.
- After a mid-cycle abort, or a start-up with any robot away from home, the cell waits in recovery for `bRecoveryConfirm` before blind sequential homing; the cycle restarts from op 1.
- The IO-mapping CSV import path and device parameter ids should be read back after setting them.
